学部生向けの観測実習の資料です。年度ごとにフォルダを分けています。各年度のフォルダに、その年のノートブック、試験観測のデータ、説明があります。

| 年度 | 対象 | 内容 | ノートブック |
| --- | --- | --- | --- |
| [2026](2026/README.md) | M57（環状星雲） | ミューロン210 の試験観測（2026-10-08）から、50cm 公開望遠鏡での写りと観測計画を予測する | [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/hsameshima/SmallTelescope_test01/blob/main/2026/notebooks/m57_practicum.ipynb) |

## フォルダの構成

```
README.md            年度の一覧（このファイル）
2026/
  README.md          その年度の使い方・日程・データの説明
  notebooks/         課題のノートブック
  data/              試験観測の FITS とマスターフラット
```

新しい年度は、前の年度のフォルダをコピーして始めます。ノートブックの最初のセルにある `YEAR` を新しい年度に変え、上の表に1行足してください。大きなデータ（1 ファイル 100 MB を超えるもの）は、リポジトリではなく GitHub の Releases に置き、ノートブックからダウンロードします。

各年度の資料は、実習が終わった時点でタグ（例：`2026`）を付けて固定します。
