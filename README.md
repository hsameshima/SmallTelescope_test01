# 小望遠鏡実習：M57 の実測データから 50cm 望遠鏡での写りを予測する

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/hsameshima/SmallTelescope_test01/blob/main/notebooks/m57_practicum.ipynb)

2026年10月8日にミューロン210（口径 210 mm）＋ ZWO ASI183MM で撮影した M57（環状星雲）のデータを使い、国立天文台 50cm 公開望遠鏡で同じカメラを使ったときの画素スケール・信号・S/N を予測して、本番の観測スケジュールを作る課題です。事前実習日の夕方には、今夜撮ったデータで予測を確かめます。

## 使い方

1. 上の「Open in Colab」ボタンを押す
2. Colab のメニューで「ファイル → ドライブにコピーを保存」を選び、自分用のコピーを作る
3. 上のセルから順に実行し、`# TODO` のセルと「答え」のセルを埋める
4. 夕方のパートでは、今夜撮った FITS を zip にまとめてアップロードする（ノートブックの案内に従う）
5. 「ファイル → ダウンロード → .ipynb をダウンロード」で提出する

10/8 のデータはノートブックの最初のセルで自動的にダウンロードされます。

## 内容

| パス | 内容 |
| --- | --- |
| `notebooks/m57_practicum.ipynb` | 課題のノートブック |
| `data/20261008/` | 2026-10-08 の FITS（Light: Ha, O3, S2, R, G, B 各 2 枚、Dark 2 枚。60 秒、Bin4、gain 111） |
| `data/20261008_flat/` | 2026-10-08 の日没前に撮った空のフラットから作ったマスターフラット（R, G, B, Ha, O3, S2。中央を 1 に規格化した圧縮 FITS、`fits.getdata(パス, ext=1)` で読む）と、元の全 160 フレームの一覧表 `flat_frames_20261008.csv` |

## 課題の構成

| いつ | 内容 |
| --- | --- |
| 日没前 | 予想を書き残す / 課題1 画素スケールと視野 / 課題2 信号とノイズの実測 |
| 薄明中 | 課題3 50cm での信号の換算（F 値の役割、星像の広がり、夜空の背景） |
| 夕方 | 晴れ：夕方A テスト露光で予測を確かめる / 曇り：夕方B 屋内で装置を測る（露出を変えたダーク、一様光源でのゲインと飽和、フィルターごとのフラット） / 共通：夕方C 1 枚あたりにかかる時間 |
| 夜 | 課題4 S/N と必要積分時間の予測 |
| 宿題 | 課題5 M57 の観測可能時間と当日のスケジュール / 課題6 予測の限界（任意：10/8 のフラットで、フラット補正の効果を確かめる） |
